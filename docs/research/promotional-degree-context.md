# Qualitative degree and benefit rankings

`filler.unscoped-assurance` version 10 adds bounded qualitative degree and
benefit-ranking constructions to the existing offline engine. The new
diagnostics request a criterion for the claim. Their advice requires checking
that criterion before weakening or removing the claim, including in mixed
groups. Technical capability, operands, conditions and uncertainty remain
source context. The rule supplies no automatic replacement.

Emphatic capability modifiers can occur in prose, short lists and headings.
Other constructions cover optimization degree, ease-to-use software artifact
descriptions and deictic superlative benefits. Formal technical properties,
negation, questions, attribution, quotation, protected operators and local
measurements remain excluded. A mechanism in the same sentence also excludes
the new construction. An unrelated neighboring sentence's mechanism does not
establish the degree of the claim.

## Evidence and limits

The hypothesis and control selection were frozen before implementation or
control results. Six separate Ptah concept pages are pinned to commit
`a641f2dd20a9c8596629f43fae0cc2f811d7f5e0` and contain 34,770 source bytes.
They provide unchanged control results, with no new positive confirmation.
Project-wide exposure history is unestablished; these are separate controls.

The [measurement record](promotional-degree-context-result.json) preserves
the registration, source identities, complete replay counts and private
evaluation hashes. Public-engine blackbox tests cover the constructions,
technical controls, literal boundaries, mixed advice, occurrence allowances,
policy exemptions and original byte spans in Markdown, MDX, Go and Python.
The CLI blackbox checks both profiles with literal and supported-criterion
controls. Run `go test ./...` or the repository's complete `make check`.
The private semantic judgments are retained locally; public tests do not
independently reproduce them.

This is a measured improvement on exposed development sources. It does not
establish unseen positive recall, population precision, probability
calibration, authorship or completion of the contextual quality goal.
No model calls, paid API requests, gate changes or frequency changes are
involved. Broad quality acceptance remains open in
[#349](https://github.com/stokaro/unswell/issues/349).
