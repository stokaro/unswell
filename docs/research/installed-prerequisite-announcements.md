# Installed prerequisite announcements

The existing `filler.instruction-scaffolding` rule recognizes an installed-tools
prerequisite expressed through the reader-directed chain `you will need to
have the following`. It diagnoses the future and possession auxiliaries and
asks for direct prerequisite wording. Advice preserves the purpose, required
installed state, versions, conditions, and optional recommended items. It also
asks the editor to retain future wording when a separate deadline or state
change makes it necessary.

The bounded construction requires an installed-state operand at the end of the
complete clause. An optional introductory purpose must name an action and its
operand. Direct prerequisites, architectural actors, permissions, optional
requirements, quotations, attribution, protected construction words, deadlines,
and additional state qualifications do not establish this construction.
This warning is a request for review, not an automatic edit or authorship claim.
