# Appraisals beside operational explanations

`filler.evaluative-closure` version 12 keeps an anaphoric appraisal separate from
the operational explanation that follows it. Coordinated and causal continuations
no longer erase a bare question or worth predicate. Deictic conversion appraisals,
demonstrative-plan completion metaphors and unqualified abstract value labels
receive the same bounded review. The existing recognizers retain precedence.

The new guidance preserves actions, numeric operands, absent operations,
qualifications and commitments. It requests direct information and verification
before weakening a claim, including when a finding combines constructions. It
provides no automatic rewrite. Literal control loops, explicit measurements and
criteria, conditional evaluations, quotations, attribution and protected
construction words remain controls.

## Evidence and limits

The hypothesis and six control sources were frozen before implementation or
control outputs. They contain 32,692 bytes from Ptah inference lifecycle guides
at commit `a641f2dd20a9c8596629f43fae0cc2f811d7f5e0`.
There are no new positive confirmation detections. Project-wide exposure history
is unestablished; these are separate controls, not an untouched product holdout.

The [measurement record](discourse-stance-context-result.json) preserves the
registration, control identities, complete replay counts, actual diagnoses and
private evaluation hashes. Public-engine and CLI blackbox tests cover literal
controls, both profiles, original UTF-8 coordinates, policy exemptions,
occurrence allowances and mixed guidance. Run the repository's `make check`.
Private editorial judgments are retained locally and are not independently
reproduced by those functional tests.

This is an improvement on exposed development sources. It does not establish
unseen positive recall, population precision, calibration or authorship.
No model calls, paid API requests, gate changes or frequency changes are involved.
