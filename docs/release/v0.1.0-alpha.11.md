Verified on November 14, 2026 for
[v0.1.0-alpha.11](https://github.com/stokaro/unswell/releases/tag/v0.1.0-alpha.11)
at `05239bd4d1bff37e11995716785d1d994809ce04`. The tag is signed and its
signature verifies. Existing tags were preserved.

All seventeen jobs in the
[release workflow](https://github.com/stokaro/unswell/actions/runs/43605604598)
passed, the Docker Hub mirror among them.

repositories; both were open when this page was written.

## The published binary and the measured pages

The measurements of `unswell fix` in the
[record](../../research/reviews/2026-11-12-human-reference/RESULTS-index.md)
were judged on pages that earlier builds wrote: 83 pages of the first run, 89
of the second, and 250 of the third. The binary from the published macOS
ARM64 archive ran `unswell fix --write` on the original of each of the 422
pages. It wrote every fixed page byte for byte as the judges read it, and it
refused the one page of the second run that the earlier build had refused,
whose Markdown does not parse. The check is
`scripts/index/reproduce_fix.py` of the record.
