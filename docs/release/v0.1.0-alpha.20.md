## The published binary and the measured pages

The fourth form of `syntax.closing-denial-density` was measured with a build
of the branch of its change, before the release. The binary from the
published macOS ARM64 archive was run on the same texts again, beside that
build, against the
[record](../../research/reviews/2026-11-18-late-denial/RESULTS.md):

| What | Pages | Result |
| --- | ---: | --- |
| The rule on every page of the record | 4,947 | The same row for each page: the same closing sentences listed with the limits of the rule, and the same closing denials counted with no limit |

That covers the fitting parts, the measured parts, and the two sets without
parts. The rule needs no model, so a run of the same binary on the same text
gives the same row.

The check is `scripts/forms.py` of the record. It needs the texts, which stay
with the maintainer.
