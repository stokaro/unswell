## The model commands in the published binary

This release adds `unswell review` and `unswell trim`. The binary from the
published macOS ARM64 archive ran both on one documentation page, with a local
assistant program serving `claude-sonnet-5-5` as the model:

| Command | Result |
| --- | --- |
| `unswell trim` | Four trims proposed, none rejected by the check, nothing written. Exit code 0. |
| `unswell trim --write` | Five trims written to the file. Exit code 0. |
| `unswell review` | Nine findings bound to source bytes. Exit code 0. |

The two trim runs gave different answers, as the documentation of the command
says a model can. This is one page, one model, and one run of each command. It
shows that the published binary reaches a model and applies its checks. It says
nothing about how good the answers are; the documentation of
[review](../review.md#measured-behavior) and [trim](../trim.md#measured-behavior)
reports that.

used.

## Docker Hub

The mirror holds releases up to alpha.4. Renew the Docker Hub token in the
repository secrets, then run the `Mirror containers to Docker Hub` workflow for
`0.1.0-alpha.6`, `0.1.0-alpha.7`, and `0.1.0-alpha.8`. The weekly
`Release prerequisites` workflow logs in with the same credential and fails
while it is rejected.
