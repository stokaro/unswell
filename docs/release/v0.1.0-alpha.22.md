The tap formula and the Action default followed through pull requests in
their repositories, and both are merged. The four checksums of the formula
equal their lines in `SHA256SUMS`, and the formula installed this version on
the four runners of the tap's checks. The action's `v0.1.0-alpha.22` tag
points to `ee69682c21152932a702ca92701a5b9447a0eb39`, the commit that the
documentation names now; its checks installed this version on Linux, macOS,
and Windows.

## The pages of this release name this release

The site builds the pages of a release from its tag. The tag of alpha.21 was
made before the documents named that version, so its pages tell a reader to
install alpha.20 ([#634](https://github.com/stokaro/unswell/issues/634)). For
this release the documents were changed before the tag, and a repository
check holds them to the version of the code. At the tag, the README, the
installation and container documents, and the two site pages with install
instructions name `v0.1.0-alpha.22`.

## The published binary and an MDX page

This release gives an MDX page the AI-sounding index
([#631](https://github.com/stokaro/unswell/issues/631)). The binary from the
published macOS ARM64 archive gives the research report of the site, an MDX
page, an index of 34 at the level `low`, the reading that the build of the
change gave. For the Markdown sample of the playground it writes the same
index lines, the same output of `unswell fix`, and the same fixed page as the
binary of alpha.21.
