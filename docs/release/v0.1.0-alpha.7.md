# Alpha.7 distribution evidence

Verified on November 12, 2026 for
[v0.1.0-alpha.7](https://github.com/stokaro/unswell/releases/tag/v0.1.0-alpha.7)
at `4c33dc1bfb24dc78c98150e91ed030467ab3fd85`. The tag is signed and its
signature verifies. Existing tags were preserved.

Sixteen of the seventeen jobs in the
[release workflow](https://github.com/stokaro/unswell/actions/runs/43178970011)
passed. The mirror job failed: Docker Hub rejected the mirror credential. Since
this release the mirror does not gate publication, so the archives, the MCP
Registry entry, and the distribution updates were published without it.

| Delivery | Evidence |
| --- | --- |
| CLI archives | [Audit](v0.1.0-alpha.7-audit.json): six archives, twelve digests, six build records, six SBOMs, and 138 bundled license files. All six binaries rebuilt byte for byte from the signed commit with `go1.27.4`. |
| Public Action consumers | The release's Linux, macOS, and Windows consumers installed the published archives through the action and checked `README.md` and `docs` under the repository policy. All three passed. |
| CLI and MCP images | [Anonymous index digests](v0.1.0-alpha.7-images.json) for both GHCR tags, each with Linux AMD64 and ARM64 and two attestation manifests. The workflow's public-image checks passed on both architectures. The images are not on Docker Hub. |
| MCP Registry | [The public response](v0.1.0-alpha.7-registry.json) identifies `io.github.stokaro/unswell` version `0.1.0-alpha.7` as active with the expected OCI package. |
| Go module | [Consumer check](v0.1.0-alpha.7-module-check.json): the published core module builds without a local replacement, with module sum `h1:oaYyqyMqDjbnsOE39XZv9mf6iDTn+CZvzoQCMHy8lOU=`. `go install github.com/stokaro/unswell/cmd/unswell@v0.1.0-alpha.7` through the public proxy installs a binary that reports the version. |

## Distribution updates

The publishing app created
[Homebrew PR #16](https://github.com/stokaro/homebrew-unswell/pull/16) and
[Action PR #16](https://github.com/stokaro/unswell-action/pull/16). Both need a
maintainer review before merging. Until then the tap's formula and the Action's
default name an earlier release. The Action accepts `version: 0.1.0-alpha.7`
explicitly, which is what the release consumers above used.

## Earlier tags of this series

Two tags precede this release without a GitHub release of their own.

- `v0.1.0-alpha.5`: the release run stopped in the mirror job, because the
  registry of the pinned mirror tool had removed its image. Its Go module cannot
  be downloaded: the source tree exceeded the 500 MB limit of the module proxy.
- `v0.1.0-alpha.6`: the Go module and the GHCR images are published and work.
  The run stopped in the mirror job when Docker Hub rejected the credential, so
  it has no archives and no MCP Registry entry.

## Docker Hub

The mirror holds releases up to alpha.4. Renew the Docker Hub token in the
repository secrets, then run the `Mirror containers to Docker Hub` workflow for
`0.1.0-alpha.6` and `0.1.0-alpha.7`. The weekly `Release prerequisites` workflow
logs in with the same credential and fails while it is rejected.

## Scope

Scan cost was not measured again for this release. This evidence does not
qualify rule precision; the

assistant reviewers. Final race, fuzzing, and coverage checks remain deferred
under their existing roadmap decisions.
