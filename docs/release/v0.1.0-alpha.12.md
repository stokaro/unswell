## The published binary and the measured pages

The measurements of the fix in the
[record](../../research/reviews/2026-11-12-human-reference/RESULTS-index.md)
were judged on pages that earlier builds wrote or reported on. The binary
from the published macOS ARM64 archive was run on the originals again:

| What | Pages | Result |
| --- | ---: | --- |
| `unswell fix --write`, against the fixed page that the judges read | 83, 89, 250, and 131 of the four runs | Every page byte for byte. The one page of the second run that the earlier build refused, whose Markdown does not parse, is refused again |
| `unswell check`, against the report that the fixer model was given in the fourth run | 131 | Every report the same |

The checks are `scripts/index/reproduce_fix.py` and
`scripts/index/reproduce_report.py` of the record.
