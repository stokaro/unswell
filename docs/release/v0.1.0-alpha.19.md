## The published binary and the measured pairs

The two results of `unswell compare` were measured with a build of the branch
of their change, before the release. The binary from the published macOS
ARM64 archive was run on the same texts again, against the
[record](../../research/reviews/2026-11-17-two-results/RESULTS.md):

| What | Pairs | Result |
| --- | ---: | --- |
| The comparison of sentences without a model, on every copy of the measured part | 374 | The same suspects, passages, and left-out words on every copy |
| `unswell compare`, from the kept answers of the judge, on the second run of the revisions | 57 | The same verdict, the same result on nothing lost, and the same sound, statements, sentences, losses, and em dashes on every pair |
| The same, on the revisions of the judge's own family, a control that was run after the release | 57 | The same on every pair |
| The same, on the copies of the measured part | 374 | The same on each of the 120 pairs that can be replayed |

The last three rows are replays that cannot reach a model. One judge is a
local program, and each of its answers is kept under its prompt. For a replay
a program gives the kept answer for a prompt and fails for a prompt that it
has no answer for. No prompt of the 57 pairs of the second run lacked one,
nor of the 57 of the control.

Some pairs cannot be replayed. Several copies of one page ask the same
question about that page, a repeated question gets a new answer, and the
store keeps the last one. So the replay of 254 of the 374 copies stops at the
statements of the page, where the store no longer holds the answer that the
check got. The first run of the revisions cannot be replayed for the same
reason: the copies were judged after it with the same store of answers. The
answers of the other judge come from an endpoint and were not kept.

The checks are `scripts/reproduce.py` and `scripts/offline_judge.py` of the
record, and `scripts/audit.py` of the
[record before it](../../research/reviews/2026-11-16-left-out-words/README.md).
They need the texts, which stay with the maintainer.
