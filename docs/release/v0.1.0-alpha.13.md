## The published binary and the measured pages

The second reading of the index was measured with the build of its change, one
commit before the release. The binary from the published macOS ARM64 archive
was run on the same texts again, against the
[record](../../research/reviews/2026-11-15-style-guide-text/RESULTS.md):

| What | Pages | Result |
| --- | ---: | --- |
| Counts, readings, and index of every page of both halves | 1,389 | The record's data file byte for byte |
| The pages of the earlier record of the index, read again | 1,924 | The record's data file byte for byte |
| Index of each revised page and of its revision | 179 and 178 for the two revisers | Every one the same |
| `unswell check`, against the report that a reviser was given | 179 and 178 | The same report on all but one page for each reviser |

The one page is a post of the style-guide set. The build that the revisers'
reports came from named runs of sentences in the index line also when the
second reading was `low`; the release names them only above `low`. The lines
of that page's marks are the same. The record's README has the two lines.

The checks are `scripts/export.py`, `scripts/earlier_reading.py`, and
`scripts/reproduce.py` of the record. They need the texts, which stay with the
maintainer.
