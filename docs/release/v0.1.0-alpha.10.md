# Alpha.10 distribution evidence

Verified on November 14, 2026 for
[v0.1.0-alpha.10](https://github.com/stokaro/unswell/releases/tag/v0.1.0-alpha.10)
at `e973e79e4b9dbf7ceb23ce6e66896653500fd673`. The tag is signed and its
signature verifies. Existing tags were preserved.

All seventeen jobs in the
[release workflow](https://github.com/stokaro/unswell/actions/runs/43579529665)
passed, the Docker Hub mirror among them.

| Delivery | Evidence |
| --- | --- |
| CLI archives | The release holds six archives, six SBOMs, and `SHA256SUMS`. The macOS ARM64 archive matches its checksum, and its binary reports the version. |

| CLI and MCP images | The workflow's public-image checks passed on both architectures. The CLI index is `sha256:c1da170a1cd694b78f0b999d04b45e2ea00fbb391fa4eb0e36d0f2f9080955b1` and the MCP index `sha256:d7326814bf1a9e75edb06d20a1e604233127210b3bed01abfdd9023125eac204`, each with Linux AMD64 and ARM64, and each the same in GHCR and on Docker Hub. |
| MCP Registry | The public response identifies `io.github.stokaro/unswell` version `0.1.0-alpha.10` as active and latest with the OCI package `ghcr.io/stokaro/unswell-mcp:0.1.0-alpha.10`. |
| Go module | `go install github.com/stokaro/unswell/cmd/unswell@v0.1.0-alpha.10` through the public proxy installs a binary that reports the version. |

The tap formula and the Action default follow through pull requests in their
repositories; both were open when this page was written.
