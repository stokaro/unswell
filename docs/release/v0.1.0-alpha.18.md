## The published binary and the measured pages

The two rules of this release, `syntax.closing-denial-density` and
`syntax.uniform-register`, were measured with a build of the branch of their
change, before the release. The binary from the published macOS ARM64 archive
was run on the same texts again, against the
[record](../../research/reviews/2026-11-17-page-habits/RESULTS.md):

| What | Pages | Result |
| --- | ---: | --- |
| Both rules on every page of the record | 4,947 | The same row for each page: the same closing sentences listed, and the same pages reported for one register |

That covers the fitting parts, the measured parts, and the two sets without
parts. The rules need no model, so a run of the same binary on the same text
gives the same row.

The check is `scripts/load.py` of the record. It needs the texts, which stay
with the maintainer.
