# Alpha.23 distribution evidence

Verified on November 19, 2026 for
[v0.1.0-alpha.23](https://github.com/stokaro/unswell/releases/tag/v0.1.0-alpha.23)
at `dfd4e8503dfe1b0df771108f49eca5a75985beae`. The tag is signed and its
signature verifies. Existing tags were preserved.

All seventeen jobs in the
[release workflow](https://github.com/stokaro/unswell/actions/runs/44550758346)
passed, the Docker Hub mirror among them.

| Delivery | Evidence |
| --- | --- |

| Public Action consumers | The release's Linux, macOS, and Windows consumers checked the whole repository with the published archives through the action, at the action commit that the documentation named then, `ee69682c21152932a702ca92701a5b9447a0eb39`. Each read 1,629 documents, and all three passed. |
| CLI and MCP images | The workflow's public-image checks passed on both architectures. | MCP Registry | The public response identifies `io.github.stokaro/unswell` version `0.1.0-alpha.23` as active and latest with the OCI package `ghcr.io/stokaro/unswell-mcp:0.1.0-alpha.23`. |
| Go module | `go install github.com/stokaro/unswell/cmd/unswell@v0.1.0-alpha.23` through the public proxy installs a binary that reports the version. |

The tap formula and the Action default followed through pull requests in
their repositories, and both are merged. The four checksums of the formula
equal their lines in `SHA256SUMS`, and the formula installed this version on
the four runners of the tap's checks. The action's `v0.1.0-alpha.23` tag
points to `1badb2d15384e23218b4fd2d29ec77f5b7fa6922`, the commit that the
documentation names now; its checks installed this version on Linux, macOS,
and Windows.

## What this release is for

The checker is the same as in alpha.22. The site builds the pages of its
default version from a release, and this release carries two changes of the
site to that version: the painted opening of the research report, and the
install instructions that name this release. For the Markdown sample of the
playground the published binary writes the same index lines, the same output
of `unswell fix`, and the same fixed page as the binary of alpha.22.
