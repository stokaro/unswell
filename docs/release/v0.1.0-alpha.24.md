points to `664a3e95d9d6a65fc1cd84c69cd216649134b608`, the commit that the
documentation names now; its checks installed this version on Linux, macOS,
and Windows.

## What this release is for

The checker is the same as in alpha.23. The site builds the pages of its
default version from a release, and this release carries one change of the
site to that version: the research report names a picture of its own for a
shared link.

After the release the address `unswell.dev/research-report/` was read without
running its script, as a chat client reads it. It gives the title and the
description of the report, and it names
`https://unswell.dev/v0.1.0-alpha.24/report-card.jpg` as the picture, which
answers with a JPEG of 1200 by 630 pixels.

The documentation workflow that ran for the tag failed at its deploy job, as
it did for every release before: the Pages environment takes no deployment
from a tag. The site was deployed by a request for a run on main. From the
next release the workflow no longer runs for a tag, and the release workflow
makes that request itself.
