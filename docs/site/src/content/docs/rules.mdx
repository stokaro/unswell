Read a row as a proposal. Every builtin rule is `experimental`: the thresholds are
initial editorial policy, and no corpus precision has been established for any of
them. Enable what your project wants to argue for, and say why in the
configuration file.

`severity` is presentation. `gate` is policy: `forbid` fails a run on any match,
`none` leaves the decision to the score. `group` is the correlation group, which
shares a cap across related rules, so it is not the same thing as the identifier
prefix that groups this page. `weight` and `cap` are index points.

<Note>
  Inspect any of these from the CLI: `unswell rules list`, `unswell rules show
  <id>`, and `unswell rules test` to execute the catalog's own examples.
</Note>
