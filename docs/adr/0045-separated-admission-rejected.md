# ADR 0045: Reject the separated editorial admission configuration

Status: Accepted

Separating editorial necessity from actual-advice safety improves complete
development recall from 96/123 to 104/123 original events. The three cohorts
reach 84.2%, 84.8%, and 85.0% recall. The whole-document cohort still has only
77.4% useful delivered criticisms, below the unchanged 85% requirement, and
five supplied suggestions have unresolved effects on meaning. The combined
candidate fails acceptance despite complete page availability.

Do not integrate this configuration as a detector or a veto over ordinary
engine rules. Retain its complete negative result, all original denominators,
uncertain and rejected deliveries, advice failures, event gains, and event
losses. The earlier four-page calibration result does not qualify the full
study. No individual predeclared component subset passes the complete screen.

The comparison changes the proposal pool and admission design together. Root
assistant review follows ADR 0041; all cohorts are exposed development data.
Admission of six cached proposal streams is not standalone generation or new
confirmation. A revised hypothesis requires its own frozen protocol and
complete measured result before acceptance can change.

The [complete evidence](../../research/reviews/2026-10-07-separated-admission/README.md)
binds the source inventory, actual model execution, frozen evaluation, artifact
audit, and public accounting checks. Related: [#349](https://github.com/stokaro/unswell/issues/349).
