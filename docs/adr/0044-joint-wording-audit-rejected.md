# ADR 0044: Reject the joint full-page wording audit configuration

Status: Accepted

The registered GPT-5.6-Sol high-effort experiment combines source-ordered
wording discovery with decisions about the current engine's suggestions.
Its transport-compatible development analysis recognizes 55 of 123 full
editorial events, loses 44 previously recognized events, and meets neither
the 80% recall nor the 85% accepted-finding requirement in any cohort.
Two pages also fail the source contract. The original strict trace execution
remains invalid; metadata compatibility is a separate analysis.

Do not integrate this configuration as a contextual detector or a veto over
ordinary rules. Retain the complete negative result, frozen labels, original
denominators, and separate transport failure. Root assistant review follows
ADR 0041 and is not independent human annotation. No calibration, authorship
claim, prospective confirmation, or product qualification follows.

The [complete record](../../research/reviews/2026-10-04-joint-wording-audit/README.md)
binds the protocol, exposed review, source identities, and aggregate result.
