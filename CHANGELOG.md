# Changelog

## 0.1.0-alpha.1

First experimental vertical slice: an offline Go library and CLI for English
prose, plain text/Markdown/GFM/Go-comment extraction, source-mapped evidence,
16 configurable rule IDs, local explainable scores and policy gates, six builtin
profiles, and text/JSON/SARIF/HTML/Markdown reports from one analysis.

This alpha does not provide calibrated probabilities, a rule DSL, suppressions,
baselines, changed-unit analysis, dependency parsing, or stable-rule precision
claims. See `docs/roadmap.md` for the remaining specification requirements.
