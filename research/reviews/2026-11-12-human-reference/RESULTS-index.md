## Page index of AI-sounding documentation

For a Markdown page of 150 prose words or more the product counts six marks per 1,000 prose words and combines the
natural logarithm of one plus each rate with a fixed weight; the index is 100 times the logistic function of the sum,
as a whole number. Level "high" is 70 or more, "elevated" 40 or more. The check recomputes the index of every page
from its counts with the weights below and fails when it differs from what the product reported.

| Signal | Weight |
| --- | ---: |
| arrow | 0.81 |
| bold-label-in-list | 0.44 |
| em-dash | 0.94 |
| emoji-at-list-item | 0.71 |
| emoji-in-heading | 0.69 |
| stock-word | 0.62 |
| constant | -1.23 |

Pages that people wrote: 566 README files as they were before November 2022, from repositories that had no
part in fitting the weights. Pairs: one Markdown file before and after a commit whose message says that it removes
AI-sounding wording, English, 150 words or more in both versions. The held-out pairs come from repositories with no
pair in the main set: unused commits of the search and short one-file edits through GitHub's web flow. Nothing about
them was used to choose a rule or to fit the index. The test part of the main set stands apart, because its pairs were
used to admit two rules.

| Held-out pairs | 189 | 0.867 | 82 | 23 | 84 | 78.1% (69.3% to 84.9%) | 58.2% | 43.4% |
| Held-out web-flow edits alone | 92 | 0.853 | 31 | 13 | 48 | 70.5% (55.8% to 81.8%) | 48.9% | 43.5% |

Of the pages that people wrote, 18 are at level "high" (3.2%) and 69 at "elevated" (12.2%).

or more, one page per repository. Each page has fixed versions. One is what `unswell fix --write` leaves, with no
model. For the others one model gets the page and one report with the same instruction: resolve what the report
points at, change nothing else, return the whole page. The report is the text report of `unswell check` with the
configuration that ships, or the findings of a third-party linter. A model fix that returns less than half of the
page, or leaves fewer than 150 prose words, counts as failed. A fixer call that returned nothing was repeated once.
