This is intended to work with existing CI artifacts and\ninfrastructure, and with minimal overhead for package maintainers.\n\nBinstall works by fetching the crate information from `crates.io` and searching\nthe linked `repository` for matching releases and artifacts, falling back to the\n[quickinstall](https://github.com/alsuren/cargo-quickinstall) third-party\nartifact host, to alternate targets as supported, and finally to `cargo install`\nas a last resort.\n\n[![CI build](https://github.com/cargo-bins/cargo-binstall/actions/workflows/ci.yml/badge.svg)](https://github.com/cargo-bins/cargo-binstall/actions)\n[![GitHub tag](https://img.shields.io/github/tag/cargo-bins/cargo-binstall.svg)](https://github.com/cargo-bins/cargo-binstall/releases)\n[![Crates.io](https://img.shields.io/crates/v/cargo-binstall.svg)](https://crates.io/crates/cargo-binstall)\n\n_You may want to\n[see this page as it was when the latest version was published](https://crates.io/crates/cargo-binstall)._\n\n## Usage\n\n```console\n$ cargo binstall radio-sx128x@0.14.1-alpha.5\ncargo-binstall:  INFO resolve: Resolving package: 'radio-sx128x@=0.14.1-alpha.5'\ncargo-binstall:  WARN The package radio-sx128x v0.14.1-alpha.5 (x86_64-unknown-linux-gnu) has been downloaded from github.com\ncargo-binstall:  INFO This will install the following binaries:\ncargo-binstall:  INFO   - sx128x-util (sx128x-util-x86_64-unknown-linux-gnu -> /home/.cargo/bin/sx128x-util)\nDo you wish to continue? [yes]/no\n? yes\ncargo-binstall:  INFO Installing binaries...\ncargo-binstall:  INFO Done in 2.838798298s\n```\n\nBinstall aims to be a drop-in replacement for `cargo install` in many cases, and\nsupports similar options.\n\nFor unattended use (e.g. in CI), use the `--no-confirm` flag.
